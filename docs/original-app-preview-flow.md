# 原版应用预览的手机流程

本说明随候选安装包交付使用。当前研发状态见[PROJECT_STATUS.md](../PROJECT_STATUS.md)；现阶段尚无新手机发布包，微信发送／实时位置、抖音无线及海外业务仍未完成验收。

面向一部Android13／vivo手机，无Root、无电脑。首页与预览衔接、已装原版导入已经完成云端界面检查；首页发送端和vivo真机仍待实际结果。

## 三步使用

1. 在天外天地图选择地点，点击“将选点带入微信 / 抖音预览”，选择应用。此按钮在原生ARM64且预览入口已安装时显示，坐标会带入预览页。
2. 首次点击“导入手机已装版本”。当前只接受固定微信8.0.79／3200、抖音40.8.0／400801的完整原版APK；版本不符或分包时按提示选择对应官方完整APK。导入只需一次。
3. 确认地点，点击“应用坐标并打开”。以后直接改选地点再打开；结束时点击“停止容器内应用和模拟”。收到地图选点本身不会启动应用或启用模拟。

预览环境需要自行登录，已有账号、聊天记录和其他私有数据不会自动迁入。系统原应用保留；本功能作用于从预览入口打开的应用。

## 后续只记一次实际结果

候选交付后，先在应用实际位置页查看蓝点／附近地点。只需记录“选点地区”“真实地区”或“找不到位置”，以及对应入口。微信发送位置、实时共享和抖音各入口分别判定，避免用一个页面代替另一项结果。

普通模拟、VPN开关、自有检查通过或写入海外坐标，均不能替代目标位置页结果。地图地点、附近内容与IP属地也分别判定。当前不要求重复旧实验或把历史日志重新运行。
