# GoGoGo Lab 45 — 国家拼音 A–Z 排序与侧边字母跳转

## 需求

Lab 44 的地点选择页已有 157 个城市、109 个国旗国家组、展开/收起、搜索和地图共享收藏。用户建议**国家旁边增加字母排序，点一下就可以快速找到目标国家**。

## 设计与实现

- 在国家列表右侧新增窄 **A–Z 快速索引栏**，根据实际展示的国家首字母生成索引；没有国家的字母不占用空间。点击字母，列表跳到该拼音首字母对应的**首个国家行**。
- 全部国家（包括收藏里的国家分组）按其**中文名称的汉语拼音全拼**排序：先按字母，再按完整拼音，同一个字母组内的国家也有稳定顺序。如 `Z` 下是“赞比亚 → 智利 → 中国”；`R` 下可定位日本等国家。
- 全部 109 个国名使用固定离线拼音映射，避免系统 Android ICU 转写差异与联网依赖；自定义收藏（无已知国家前缀）按 `#` 分组，放在国别之后。
- 右侧索引是独立的可滚动窄栏（约 36dp），手机屏幕很矮时也不会把 20 多个字母挤成无法点按的超小目标。每个字母有可读的无障碍描述。
- 用户展开多个国家后，城市行会导致 ListView 位置改变。索引位置由 `LabPlaceAlphabet.headerAnchors` 基于**当前真实可见城市数量**计算，确保展开或收起国家后，字母仍跳到正确的国家标题。
- 有搜索词时，国家与城市匹配结果已经自动展开，因此自动隐藏侧栏，把宽度让回给搜索结果。清空搜索则恢复侧栏和按拼音排序的浏览视图。
- 收藏页显示多个国家时同样可使用索引；旧地图自定义收藏、保存数据和星号按钮原样保留。
- 仍为**选城市才填坐标／移动地图**；点击国旗、国家标题、展开加号或字母索引都不会自动启动 ServiceGo 模拟。

## Android 13 真机验收

- [ ] 打开国家选择页，确认右侧出现 A–Z 字母栏；中国在 Z 下，日本在 R 下，按完整拼音顺序排列。
- [ ] 点 `M` 跳到美国、缅甸等国家所在区；点 `Z` 跳到赞比亚、智利、中国所在区。
- [ ] 展开中国多个城市、展开其他国家，再点击 R／Z，确保依然跳到正确国家标题而非错误的城市行。
- [ ] 输入「中国 上海」，右侧索引隐藏，地图/首页的可视宽度恢复；清空搜索重新显示字母索引。
- [ ] 在“我的收藏”有多个国家时右侧索引可跳转；单个国家或者只剩自定义收藏时隐藏索引也不会影响直接选点。
- [ ] 短屏、高系统字体、中文长国家名、软键盘下索引不会遮挡加号、星号或内容。
- [ ] 点击字母不更改选中位置，不启动模拟；只有点击城市行才返回坐标。
- [ ] 真机 Emoji 字体、列表跳转和可点击区域仍需手工检查；Gradle 测试不能替代设备实测。
