# 天外天：全球地点搜索 V1

本次目标：地图首页轻量搜索入口 → 独立搜索页 → 点击结果回到地图修改 WGS-84 目标位置。**不启动模拟、不断开原模拟、不修改 ServiceGo 注入逻辑。**

## 三种搜索

1. **离线预设**：输入时即时本地筛选 263 个预设（193 个国家）。完全离线、不发请求。最多展示前 12 项，完整地点库按钮仍可展开全部列表并返回结果。
2. **坐标直达**：支持 `98.50895,16.68914`、中文逗号、空格和 `经度:98.5 纬度:16.7`。输入顺序固定为经度、纬度。沿用 `LabHomeCoordinates.parse` 校验 NaN/Infinity/范围错误，返回地图只更新目标。
3. **在线地名搜索**：按「搜索全球地图（联网）」或键盘搜索键才请求 Nominatim 兼容地理编码服务，不在文本输入时发送请求。默认 5 条在线结果；请求超时、无结果、接口拒绝均清晰提示，离线功能继续可用。

## Nominatim 使用约束

- 默认：`https://nominatim.openstreetmap.org/search`。
- API 文档：https://nominatim.org/release-docs/latest/api/Search/
- OSMF 公共实例政策：https://operations.osmfoundation.org/policies/nominatim/
- 仅用户明确提交（禁止 autocomplete、预取、自动重复查询和后台批量搜索）。
- 每进程发送请求间隔至少 1.2 秒；全局单工作线程；单查询不超过 120 Unicode 字符，最多 5 条结果；连接和读超时各 8.5 秒。
- 标识应用 User-Agent（含仓库网址），Accept-Language 中文优先。
- 本机 SharedPreferences 缓存 7 天、最多 24 个关键词结果；提供清除缓存入口。用户查询会发送至所选服务器；本机缓存中只用 SHA-256 的 query+endpoint 作查找键（结果名称/坐标仍以原文保存）。
- 「在线搜索服务设置」允许更换 Nominatim 兼容 HTTPS `/search` 接口，不需要更新 APK；切换时清缓存。
- 显示 `© OpenStreetMap contributors · ODbL`，可点击官方许可链接。
- **重要上线条件**：公共 Nominatim 不是高并发商用后端。上述每设备节流不等于全平台总量节流；若面向大量用户公开分发，应改为自建 Nominatim 或明确有服务等级协议的地理编码提供商，不要依赖 OSMF 公共服务。
- 此功能定位为低频、手动的实验/个人测试版本。公共端点可能因策略或地区原因拒绝访问，切换服务或使用离线预设作为回退。

## 回归重点

- 正常中文与英文地址，GPS 经度/纬度范围错误、坐标中英文逗号；输入过程中网络请求数为 0。
- 点击在线搜索后只发出一次，重复相同查询命中本机缓存；不同查询遵守 1.2 秒最短间隔。
- 返回地图后更新标记/相机与坐标，但不调用 `ServiceGo`。
- 深入「完整地点库」选点能够正确逐层回传，不会丢失。
- 小屏和横屏搜索框、虚拟键盘、网络失败反馈能正常显示。
- 搜索接口被禁止（403）、节流（429）、断网时离线模式仍正常。
