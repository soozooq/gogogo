# GoGoGo Lab 44 — 全球地点选择页的流畅度和小屏交互收尾

## 发现的实际性能问题

Lab 43 的 109 个国家标题、157 个城市使用同一 ListView，但它的 Adapter 在 `getView()` 里**无条件创建新的国家/城市布局、标题、坐标控件、MaterialButton 和背景**，完全忽略 `convertView`。展开较多国家、长时间滚动以及搜索时会重复分配 Java/View 对象。

此外，每显示一个城市行都调用 `LabStore.isFavorite()`，它通过 SharedPreferences 重新获取整个收藏 JSON，反复解析成数组和对象；收藏达到几十条时会造成不必要的主线程工作。旧页面也没有一键清空搜索的入口，窄屏长国家名容易压缩加号操作区。

## 实现

- **两种 View 类型真正复用**：`PickerAdapter.getViewTypeCount()=2`；国家 Header 和城市行各自有 ViewHolder，`convertView` 非空时复用已有控件、重新绑定文字、点击监听与无障碍描述。国家/城市互不交叉复用，避免误把“加号”绑定到“收藏星号”。
- **收藏按刷新周期读取一次**：新增 `favoriteSnapshot`，`refreshResults()` 统一取当前地图共享的 `LabStore` 收藏内容，`getView()` 只遍历最多 100 个已读记录，不再每行重读 JSON。用户点星号后写回相同 `LabStore` 并立即刷新快照。
- **匹配判定一致**：抽出纯 Java `LabPlaceCoordinateMatch.same()`，收藏去重、增删收藏、列表星号状态使用同样的 `1e-6` 度容差及非有限数值保护。新增 8 个纯 Java 回归测试。
- **搜索效率和可用性**：输入框右侧新增明确的“×”清空按钮，软键盘支持搜索动作，首次进入不主动弹键盘，打开键盘时布局可调整。切换标签仍保存搜索词。
- **旋转恢复完整**：Lab 43 已保存普通浏览时展开的国家；本轮进一步保存搜索状态下**手动收起**的国家，下次重建不会又突然全部展开。
- **小屏阅读**：国家名与城市名过长时单行尾部省略，地点与坐标都可完整通过选择结果读取；数量栏更精简，右侧按钮保留不小于 48dp 的交互宽度，国家和城市行有明确的最低触摸高度。
- 首页/地图仍调用同一个地点页；选城市只回填目标坐标或移动地图标记，不触发 `ServiceGo`。保留 157 个地点、109 个国家国旗、搜索和原有收藏内容。

## 回归测试与验收

- [ ] Android 13 手机上滚动 109 个国家列表、多次搜索、逐个展开城市，感受是否比 Lab 43 更顺畅；比较触摸卡顿与列表跳动。
- [ ] 在收藏超过 20 条时连续滚动、展开、收藏/取消收藏，星号能立即正确更新，切换“我的收藏”看到同样数据。
- [ ] 搜索输入「中国 上海」，点击“×”，搜索词清空并恢复国家折叠浏览；键盘不会遮住全部结果。
- [ ] 在搜索结果中手动收起日本，旋转手机后仍收起；清空搜索后回到常规展开状态。
- [ ] 在窄屏、高字体比例下检查国家长名称不覆盖城市计数或加号；星号和加号仍可分别点击。
- [ ] 确认点击国家与加号不更新坐标，点击城市行才会向首页或地图返回有效 WGS-84 经纬度。
- [ ] 在地图中已有的自定义收藏仍在“📍 我的自定义地点”，其标签、坐标没有被迁移或删除。
- [ ] 真实设备的帧率、字体 Emoji 国旗与触摸表现仍需实际测试；GitHub 编译结果本身不能证明手机体验已验收。
- [ ] 单测包含 `LabPlaceCoordinateMatchTest`，覆盖经纬度顺序、正常舍入误差、容差边界、NaN/Infinity；继续运行原 `LabPlaceCountriesTest` / `LabPlaceSearchTest` / `LabLocationPresetsTest`。
