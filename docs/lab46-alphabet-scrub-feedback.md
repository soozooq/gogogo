# GoGoGo Lab 46 — A–Z 侧边栏快速滑动与触感反馈

## 起因

Lab 45 已完成 109 国按中文拼音的 A–Z 排序与右侧字母跳转，但用户需要在实际手机上快速连续查找多个国家。原实现只能**单独点击每个 24dp 字母**，跳转后没有明显的当前字母标记，也没有触觉确认。

## 本轮打磨

- **指尖连续滑动**：按下字母栏即选中对应字母，手指按住沿索引上下移动时，左侧国家列表连续跳到新的拼音首字母组。不是给每个字母另加页面/按钮。
- **短屏边缘辅助滚动**：已有字母栏支持独立滚动，手指拖至上、下边缘时，会逐步滚动字母栏并继续定位当前手指下的字母；目标行按正在滚动的 `scrollY` 计算。
- **视觉反馈**：当前字母使用现有 GoGoGo 配色高亮，列表上方提示“已跳至 X”；切换字母时才更新高亮，避免无意义重绘。
- **轻触感**：使用 Android 系统标准 `KEYBOARD_TAP` haptic feedback，随用户系统触觉设置生效；不新增振动权限、不持续震动。
- **保留无障碍点击**：TalkBack/键盘通过字母项的正常 `performClick()` 路径跳转。拖动完成不会跳回手指一开始按住的字母。
- **重复点击可返回**：如果当前高亮仍为 `M`，用户手动滚动国家列表离开了 `M` 区，再次点 `M` 必须重新定位。
- **高效无后台任务**：拖动取样基于真实当前 `ScrollView` 屏幕坐标与滚动量，没有轮询、后台服务或额外地理网络接口。
- **不改变原有功能**：保留 157 个地点、109 个国家、国家国旗与加号展开、拼音排序、搜索自动隐藏字母栏、共享收藏与首页/地图选中坐标协议。仅选城市才能回填坐标，不会因点/拖字母而启动模拟。

## 回归测试

`LabAlphabetRailTouchTest` 新增 9 组 JVM 测试：字母行 hit-testing、手指跨行滑动、滚动 `scrollY` 位移、越界手指钳制、NaN/Infinity、边缘自动滚动触发边界、极大滚动值保护。继续运行 Lab 45 的国家拼音排序与展开路点位置测试以及此前收藏等测试。

## Android 真机手动验收

- [ ] 打开“国家与城市”，按住 A–Z 右侧字母栏，上下移动，左侧国家标题随着当前字母变化移动且不会出现错误国家。
- [ ] 手指拖动时选中的字母被明显高亮；手机触感在字母**改变时**触发而不是每帧重复震动。手机系统关闭触觉时应尊重系统设置。
- [ ] 手指拖到侧边栏底部继续缓慢移动，字母栏可逐步向后滚动；靠近顶部反向操作也正常。
- [ ] 重复点击同一字母仍可跳到首个对应国家；刚展开多个国家后依然跳到正确标题。
- [ ] Android TalkBack 模式下，可以读出每个字母并通过正常点击激活，不依赖拖动。
- [ ] 在 360dp 以下窄屏、系统大字、横屏/短屏时仍能操作 A–Z，同时国家加号和城市星号保持可点。
- [ ] 输入国家/城市搜索词时字母栏按 Lab 45 规则隐藏，清空搜索后可继续操作；“我的收藏”多国分组也适用。
- [ ] 仅点字母不提交坐标、不启动模拟。坐标只有实际选择城市行才返回首页/地图。
- [ ] GitHub 绿灯不代表手机实际滑动手感、触觉、无障碍和帧率都验收通过，需要设备复核。
