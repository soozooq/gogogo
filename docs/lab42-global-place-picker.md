# Lab 42 — 全球国家城市搜索与共享收藏

## 本轮解决的体验问题

此前首页和地图都使用 `AlertDialog.setItems(LabLocationPresets.labels())`，仅 **17 个**固定预设。直接扩容会制造过长的滚动列表，也无法按国家/城市关键词定位。地图已有 `LabStore` 收藏夹（最多 100 条），但首页没有入口。

## 实现

1. 原有 17 个城市的顺序、默认缅甸妙瓦底坐标均不变；离线 WGS-84 参考地点新增 140 个，现有共 **157 个**，涵盖 **100+ 个国家/地区名称**，包括亚洲、欧洲、非洲、美洲和大洋洲。
2. 新增唯一的常用 **`LabPlacePickerActivity` 地点选择页**，取代首页和地图重复的 17 项弹窗。该页面默认展示全部预设并提供实时国家/城市文字筛选（空格分词、大小写不敏感），不依赖联网地址解析、Token 或地图商业 API。
3. **全部预设 / 我的收藏** 两个标签。预设行点击即选择；独立星号可以收藏或取消收藏。收藏列表直接读取、修改地图此前使用的 **同一个 `LabStore` SharedPreferences 文件**，既包括新增的预设收藏，也包括用户曾在地图上手工收藏的自定义地点。
4. 地点选择通过 `ActivityResult` 返回合法的经度、纬度给调用方。**首页只填入坐标输入框，地图只更新选点和视口，不启动 ServiceGo 或路线模拟**。取消/普通返回不修改位置。
5. 所有返回的经纬度再次由 `LabHomeCoordinates.parse` 检查 `NaN`、`Infinity` 和 WGS-84 范围。收藏页面保存状态只有搜索词和当前分类，不存巨量地点对象。
6. 不改 Android 权限、GMS/Provider 注入、Shizuku、地图本体或后台生命周期。

## 自动化回归测试

- `LabLocationPresetsTest` 要求离线地点不少于 150 个、国家/地区名至少 100 个、名称和坐标不重复，且原 17 个顺序保留、WGS-84 数值合法。
- `LabPlaceSearchTest` 新增 8 个用例：空查询、国家筛选、城市筛选、多个关键词交集、中文标点、英文收藏名称大小写、空名称和无匹配。
- 原有 `LabHomeCoordinatesTest` 保证坐标验证兼容；Gradle 构建、JUnit、Lint、Preview APK 打包作为 PR 合并门槛。

## Android 手机真机验收

- [ ] 首页点「搜索国家 / 城市 · 收藏」，看见独立搜索页面和超过 150 个离线预设，不再显示旧 17 项 AlertDialog。
- [ ] 搜索「中国」能看到多座城市；搜索「东京」「妙瓦底」分别缩小到对应城市；搜索「中国 上海」只显示上海。
- [ ] 点预设行，返回首页经纬度输入框自动更新；服务并不启动。取消返回不修改当前输入。
- [ ] 点击星号将预设收藏、再次点击可取消；点「我的收藏」直接可选择收藏坐标。
- [ ] 地图中此前保存的自定义收藏也出现在「我的收藏」列表；从收藏选中一个地点后，地图标记和视口移动，但必须再手动点击「模拟这里」才会发布。
- [ ] 在地图工具菜单点「搜索国家 / 城市 · 收藏」，与首页共用同一收藏数据；在两端增删后能够相互同步。
- [ ] 搜索关键词、收藏分类在旋转屏幕时仍在；大字体、窄屏和软键盘打开时可操作。
- [ ] 高密度列表滚动无卡顿、无重复收藏数据、坐标精度符合预期。
- [ ] 位置是**近似城市地标中心参考坐标**，并不是实时在线地理编码或导航地址；不应把地理搜索当作每条街道的精确坐标服务。
- [ ] 依旧以真机系统和第三方消费端实际回调作为模拟定位兼容证据。
