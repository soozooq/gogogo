# GoGoGo Lab 40 — 地图坐标回填与启动状态反馈

## 用户可见行为

原首页 SimpleMockActivity 可以把手动输入的坐标带入 MapLibre 地图作为起始视口，但用户在地图上点选新位置后按返回，原首页坐标并不会改变。地图已有“模拟这里”按钮，但这个操作会立即向 ServiceGo 发起模拟，不适合作为“先选点再回首页确认”的替代方案。

本轮增加 **“填入首页（不启动模拟）”** 明确入口：
1. 首页点击“地图选点与路线”，起始坐标仍传入地图。
2. 在地图上点击、从收藏/历史选取或从城市预设选择位置。
3. 点击新按钮，地图把合法 WGS-84 选点作为 Activity Result 传回首页，仅更新经纬度输入框，然后关闭地图。
4. **直接按地图返回、系统返回、打开工具后返回不会回填**；地图上的“模拟这里”仍保留原功能。
5. 如果模拟服务已经运行，回填不会修改当前服务坐标，也不会调用 ServiceGo；必须在首页再次手动点击“开始模拟”才提交新输入。

Activity Result 在首页使用 androidx.activity.result API 注册，回填时再次用 LabHomeCoordinates.parse 验证有效、有限且经纬度在范围内，拒绝意外丢失、无效或越界的结果。

## 启动/停止状态反馈

旧首页点击“开始模拟”后，即使操作只是提交一个 startForegroundService 请求，也立即显示“已请求启动”；一旦 Android 拒绝前台服务启动，异常还可能直接导致 Activity 崩溃。点击“停止”同样没检查 stopService 的返回值。

当前行为：
- **精确定位权限尚未授权**：提出申请并停止当次启动流程；用户授权后需再次手动点击“开始模拟”，避免异步权限请求尚未完成就启动服务。
- **系统拒绝启动或停止请求**：捕获 RuntimeException，显示安全的失败提示；不会宣称成功。
- **系统返回 null 启动结果**：保守提示“未确认”，不当作已启动。
- **停止时系统找不到正在运行的服务**：显示“不存在可停止的服务”，不冒充停止请求成功。
- **请求接受后**：用户立即看到请求状态，之后只在短时间内检查本进程的 `ServiceGo.sRunning` 标记，按“RUNNING/STOPPED/仍未观察到预期状态”显示说明。UI 不会因为异步请求一接受就显示“定位模拟成功”。
- **不额外采集位置**：状态检查只读取进程内标记，不调用 GMS、Wi-Fi、Shizuku 或系统 Provider，也不新增后台持续轮询。
- 保留 Lab 39 的“设备设置与自检”折叠与按需详细诊断行为。

## 自动化验证

`LabHomeServiceStatusTest` 新增 10 个纯 Java JUnit 测试，覆盖未发起动作的 RUNNING/STOPPED、启动请求未确认、已观察 RUNNING、超时未观察到 RUNNING、停止请求未确认、已观察 STOPPED、超时仍 RUNNING、null 状态动作、不能将相反进程标记认作确认。Lab 39 的坐标合法性回归继续验证输入和 Activity 回填共享的 `LabHomeCoordinates.parse`。

## Android 真机验收清单

- [ ] 首页输入自定义坐标 → 地图初始视口定位到所选位置。
- [ ] 地图上选择别处 → **按普通返回**，首页输入值保持不变。
- [ ] 地图上选择别处 → **点“填入首页（不启动模拟）”**，回首页两个输入框都更新，ServiceGo 不被启动或修改。
- [ ] 模拟正在运行时使用回填，确认地图选点只改输入框；再次手动点击首页“开始模拟”才提交新位置。
- [ ] 从地图城市预设、收藏和历史选点，回填功能依旧有效。
- [ ] 系统拒绝前台服务启动、缺少精确定位授权时，首页显示提示而不闪退或假报 RUNNING。
- [ ] 点击停止时，验证本进程状态标记变化；断网、GMS 不可用时也不能把状态标记当作第三方已恢复真实位置的证明。
- [ ] 窄屏、高系统字体、旋转、后台返回等情况下布局及 Activity Result 工作正常。
- [ ] 原地图“模拟这里”、路线/漫游/回放以及实验与诊断入口仍可用。
- [ ] 在用户自己的 Android 13 环境独立验证第三方实际位置。构建成功不能代替微信/GMS 兼容测试。

## 限制

本轮不修改 ServiceGo 内部位置发布逻辑，也不保证 AppOps、GMS 服务、Provider 或第三方缓存状态。ServiceGo.sRunning 只能代表本应用进程中的生命周期标记，不等于其他应用采用模拟坐标。

版本 `2.4.0-lab40`，versionCode `2400045`，`com.soozooq.gogogo.test` 的 ARM64 Debug Preview 使用公开测试签名，不能直接当正式发布包。
