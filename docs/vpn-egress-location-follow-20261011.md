# VPN 出口 IP → GoGoGo 模拟坐标联动（2026-10-11）

## 用户意图

开启后，当用户切换系统 VPN 节点，GoGoGo 自动更新正在运行的模拟位置到该出口 IP 的**近似**国家/城市，避免 VPN 网络地区与模拟位置配置明显不一致。默认关闭且不可代替手动定位。

## 行为与边界

- 首页经纬度下方新增「VPN 出口 → 模拟定位联动」：开启/关闭持久开关、状态、手动刷新。
- 开启后由**已经运行中的 ServiceGo** 注册 Android `ConnectivityManager.registerDefaultNetworkCallback`，只对 GoGoGo 自己的默认网络检测 `TRANSPORT_VPN` 和 `NET_CAPABILITY_INTERNET`；不枚举设备别的 App 的 VPN 状态。
- 通过 `Network.openConnection` 在**该 VPN 网络**上以 HTTPS 向 `https://ipwho.is/?fields=success,country,city,latitude,longitude` 请求出口城市坐标。不读取手机真实 GPS、IP 响应中的公网 IP 不记录、不展示、不上传到诊断日志。公网出口 IP 会被第三方服务自然看到，故需要用户明确开启开关。
- 收到网络变化时防抖更新；同 VPN 网络无网络层事件的节点切换，由固定 **180 秒** 再检查一次，或点击「立即检查」刷新；手动刷新防频繁请求。网络 I/O 均在后台执行，主线程只在满足安全门槛后改变已有 ServiceGo **固定模拟位置**，复用当前 Provider / GMS mock 管线，不新增 provider 或注入后门。
- 进入路线、漫游、回放时只记录状态，不覆盖模拟目标；返回固定模式后下一轮周期查询重新生效。没检测到 VPN、VPN 已断开、服务未运行、HTTP 失败、坐标不合法、未明确授权时，**不改变模拟坐标，也不会去读真实位置或自动退出模拟**。
- 关掉开关不清理当前已有的模拟坐标；需用户手动选点或停止模拟。已有服务运行时可从首页直接启停同步；不开模拟服务不会额外启动后台服务。
- 只存储解析出的城市/国家、经纬度及最近应用时间用于首页同步展示。服务进程结束后不会偷偷在后台独立运行；模拟服务重启时继续遵守持久配置。因 Android 网络限制、VPN 分应用策略/绕过策略或代理协议差异，GoGoGo 的 VPN 网络可能不同于微信的网络。
- IP 的城市数据库不是物理定位证据；手机 GPS / Wi-Fi / 基站 / 腾讯 LBS 的坐标来源也不能因此保证和 VPN 一致，微信 UI 的自动定位需独立测试。

## 本轮验收点

- [ ] 开关默认关闭，无外部 IP Geo 请求，不改变旧的正常开始模拟/停止模拟
- [ ] VPN 连接且 GoGoGo 流量被 VPN 覆盖：开启后按出口近似坐标自动应用，首页输入框跟随显示
- [ ] 切换 VPN 国家节点：Android 网络变更后快速刷新；如果节点切换没系统网络事件则定期刷新
- [ ] VPN断开或分流导致 GoGoGo 不走 VPN：不把实体网络的位置写入 mock
- [ ] 线路/漫游/轨迹回放模式中不被 VPN 同步覆盖
- [ ] HTTPS 失败、接口速率限制、异常 JSON/坐标和快速反复启停不发生意外坐标覆盖
- [ ] 手机上的主微信 / vivo 分身是否接受同步后的坐标仍记为独立的、未验证的实验结果
- [ ] 新版本安装时不因签名不一致覆盖用户数据（预览包仅供测试，不使用生产密钥）
