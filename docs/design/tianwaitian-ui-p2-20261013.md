# 天外天 Android UI · P2 主线迭代记录

日期：2026-10-13  
源码：`soozooq/gogogo` · 直接提交 `main`  
预览版本：`2.4.2-tianwaitian-preview` / `versionCode 2400070`

## 本轮改动（均为 main 原码，无新功能分支）

1. 首页品牌卡加入折叠控件，默认高度不足 600dp 的屏幕折叠，**模拟按钮仍可使用**。
2. 横竖屏调整品牌卡宽度；保留右侧地图操作区域；狭窄卡片和系统大字体切换操作按钮为竖排。
3. 增加首页「地点库」快捷入口，使用 `ActivityResultLauncher` 接收 `LabPlacePickerActivity` 的 WGS-84 坐标和名称。
4. 地点库的选点结果经 `MapUtils.wgs2gcj02` 转为旧 Tencent 首页使用的显示坐标；**只填入目标，不会启动 `ServiceGo`**。
5. 为 `LabResponsiveUiPolicy` 加入可复用的 P2 布局规则和 JUnit 覆盖（宽度、屏幕高度、字体缩放）。
6. 设置页增加可复用的星座主题品牌头部，原 `PreferenceFragmentCompat` / 数据 key / 选项未改变。
7. 地点库增加离线坐标数量提示，统一搜索文案、A–Z 索引底板样式；诊断中心突出「只读总览、快速检查、深入排障」。
8. 修正全球坐标文案：国内区域与境外地点的偏移规则不同，不能统称「GCJ-02」。
9. 更换预览版版本号便于 Android 覆盖安装区分。

## 限制与真实验收条件

- 此轮无 `ServiceGo`、GMS、Framework Mock、微信兼容或 Shizuku 注入修改；按钮只是导航/显示，不将 Task 成功宣称为第三方采用。
- 地图与首页的坐标系转换依赖之前加入的 `ChinaGcjRegion`，目前仍为 Natural Earth 110m 粗尺度边界；接近国境和海岸线时需实机与高精度数据核对。
- 用户曾报告 vivo V2134A Android 13 双开微信位置仍停留福建；**这次 UI 变化不能视为已经兼容微信**。
- 演示星座矢量为品牌纹样，不是核实注册的独占商标或正式 Launcher Logo。
- 旧签名密钥的仓库安全风险尚未处理，正式发布前必须迁移到非公开、安全保存的签名策略；切换签名密钥可能影响既有安装包的直接覆盖升级。
- 本记录仅描述代码更改；GitHub CI 与真机测试必须以对应 HEAD 结果单独确认。
