# GoGoGo Lab 43 — 国旗国家分组与可展开城市列表

## 需求

Lab 42 把 17 个城市扩容到 157 个，加入了国家城市离线搜索和共享地图收藏夹。全部预设仍是 157 项平铺列表。Lab 43 根据用户建议，改为**先显示国家，点国家后面的“＋”再选择城市，并显示国旗**。

## 本轮改动

- 所有 **157 个离线预设**依然存在，保留原有妙瓦底默认位置、经纬度、搜索页面、收藏、首页／地图回填流程。
- 离线新增 **109 个国家到 ISO 3166-1 alpha-2 的映射**。国旗由两个 Unicode Regional Indicator 字符生成（由 Android 系统字体渲染），不需要下载图片或联网 API。
- 列表每个国家初始只显示一行：**“🇨🇳 中国 · 10 个城市  ＋”**。点击整行或者右侧 ＋ 展开城市，右侧变成 －；再次点击收起。城市行显示市名和原有 WGS-84 经纬度，右侧星号支持加入/取消收藏。
- 输入“日本”或者“日本 东京”等关键词时只显示匹配的国家与城市，并**自动展开**匹配结果。用户仍可在搜索时手动收起某个国家；改变搜索词后自动重新展开。
- 我的收藏页也按国家折叠分组，已收藏的旧自定义地点（无已知国别前缀）归入 **“📍 我的自定义地点”**，不会凭空给它们分配国旗。星号删除和地图既有 LabStore 仍完全共用。
- 切换预设／收藏标签不会清空搜索词。普通浏览时展开的国家在旋转手机后恢复（小型字符串状态，不存巨量地点或经纬度对象）。搜索查询继续由 Lab 42 savedInstanceState 恢复。
- 只选某个城市才向首页或地图返回经纬度；点击国家和加号**不会**选中城市，更不会启动/更改 ServiceGo 模拟。
- 不修改 ServiceGo、Shizuku、GMS、MapLibre 地图提供者或后台模拟机制。

## 自动测试

新增 `LabPlaceCountriesTest`：验证 157 个地点的国家全部受支持、覆盖 109 个国名、国旗由两个区域字符组成；检查中国/日本/美国/缅甸/法国国旗；城市名称提取；未知前缀归自定义分类；null/空值；中英城市筛选。运行已有 `LabLocationPresetsTest`、`LabPlaceSearchTest` 作为跨版本回归。

## Android 手机验收清单

- [ ] 打开首页地点搜索，默认看到国家列表而非 157 个平铺城市。
- [ ] 看到“🇨🇳 中国 · 10 个城市 ＋”等样式；点击＋后城市展开（北京、上海、广州、深圳等），再点－可收起。
- [ ] 点击**国家行和 ＋ 不会自动选中坐标**；只有点城市行才填入首页经纬度。
- [ ] 在搜索框输入“东京”，自动出现已展开的“🇯🇵 日本”分组且只列出东京；输入“中国 上海”只显示上海。
- [ ] 搜索状态下手动收起某个国家仍能展开回来；清空搜索恢复正常默认折叠状态。
- [ ] 城市星号可收藏/取消，在“我的收藏”看到国旗国家分组；以前地图收藏的自由命名地点出现在“📍 我的自定义地点”。
- [ ] 从 MapLibre 地图的国家城市入口打开同一页面并选城市，只更改地图选点和视角，不暗中模拟。
- [ ] 旋转屏幕时搜索词、展开状态和收藏分类正确保留；大字模式和 360dp 以下窄屏中右侧 ＋ 没有被挤到屏幕外。
- [ ] 系统手机字体能显示 Emoji 国旗。如果厂商字体不支持，仍应保留明确国家文字标识。
- [ ] 核心模拟的实际第三方消费者兼容仍需单独实机验证，此次不是关于 Provider/GMS 的修复。
