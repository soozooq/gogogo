# 定时复制诊断日志 · 2026-10-11

## 功能
- 首页、实验与诊断、Consumer Matrix（含被动快照）都有 **10 / 30 / 60 秒**倒计时复制，支持取消和重新计时。
- 使用 `SystemClock.elapsedRealtime()` 计算剩余时间，主线程回调迟到后直接按真实时间结算，而非累计逐秒偏差。
- 结束时调用用户明确启动的 `LabSupportLog.copyWithResult()`，复制**当时已保存**的最近诊断记录。不会自动拍被动快照、主动请求定位、启动/停止模拟、申请权限、连接网络或上传日志。
- 到点提示复制成功或失败；页面被销毁会取消。应用切后台或手机休眠时，Android 可能延迟回调；本功能**不是操作系统精确闹钟**。后台剪贴板行为以实机为准。
- 计时器与旧版一键复制完全独立；不使用后台服务或悬浮权限。

## 日志变更
- 单条保存上限由 650 提升到 1800 字符，保证五通道完整记录不会在 GMS updates 前被截断（仍需实机检查极长特殊数据）。
- 保留每类最多 14 条本地记录；默认复制最近 4 条主动、9 条被动和 4 条腾讯日志，避免跨轮旧记录大量重复。
- 对非首页入口，`target_lon/lat` 会回退到**最后一次申请的模拟目标**，并标记 `target_source=LAST_REQUESTED_NOT_CONFIRMED`，不暗示模拟已经成功；无目标时显示 `UNKNOWN`。
- 修复字面 `\\n` 误输出；新增倒计时/截取最近完整行的单元测试。
- `SERVICE_LIFECYCLE` 属于历史/本进程状态，独立 `:consumer` 进程的 STOPPED **不等于**主进程服务当前已停止。此次没有修改 ServiceGo 的停止与注入逻辑。

## 使用
1. 先打开需要测试的页面。如果需要采集动态 Consumer 数据，请保持普通 Consumer Matrix 页面活动；被动模式必须**先手动拍快照**，计时器不会发起额外缓存读取。
2. 选 **10秒、30秒或60秒**，页面显示倒计时。
3. 到点自动复制后，切回 ChatGPT 粘贴即可。
4. 点「取消倒计时」可以取消；重新选时间将重新计时。关闭该页面则计时终止。

## 需要手机验收的边界
- 用户是否能在不同字体缩放下找到倒计时按钮。
- 10秒结束后是否只触发一次剪贴板写入，取消后不会写入。
- 后台/锁屏下是否延迟，不能宣称精确到秒。
- GMS updates 完整行、目标标识、历史摘录数量。
- 微信定位仍未解决；这些工具仅采集公开 API 的本机实验数据，不证明微信内部来源或绕过检测。
