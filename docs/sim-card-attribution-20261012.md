# GoGoGo · 手机卡归属地 / 号码段开户省市（2026-10-12）

## 用户需求

用户希望在当前已有 VPN 国家、模拟位置与时区控制的基础上，查看手机卡归属地。**需要区分三类信息**：

1. SIM 运营商及发卡国家：Android TelephonyManager / SubscriptionManager 从本机 SIM/eSIM 环境读取；多卡详情需用户单独授权 `READ_PHONE_STATE`。
2. 中国大陆手机号码的开户归属省市：基于手机号**前 7 位号段**的历史运营商数据库，**非当前所在地**，也不等于当前网络运营商（携号转网、虚拟运营商可能导致不一致）。
3. 当前手机位置与 VPN 出口位置：来自 GPS/GMS / VPN，和 SIM 发卡地区/号段开户省市**均不必然相同**。

## 功能入口

- 首页「常用入口」新增「手机卡归属地」独立页面，沿用 GoGoUi 现有样式，不与微信实验的自动任务混合。
- 页面打开时可显示无需额外敏感授权能访问的 SIM 国家（ISO）、SIM 运营商、MCC/MNC、当前蜂窝网络国家/运营商、漫游标志；不足权限时清楚说明未知。
- 点击「授权查看双卡 / eSIM 详情」才请求 `READ_PHONE_STATE`（manifest 早已有该权限，无新增权限）。然后显示每个 active subscription 的卡槽、运营商、发卡国家、MCC/MNC，**不读取 ICCID/IMSI/MSISDN、SIM 序列号、完整手机号码，也不自动触发短信/通话权限**。
- 中国号码段归属地采用 `cn.lalaki:phone_location_android:1.2.1` (Maven Central, Android AAR, MIT metadata)，离线查询号码前 7 位。号码输入框限制 7 位，使用本地包内数据库查询；无网页 API 请求、无本地历史记录，不把输入加入共享诊断日志。
- 首次本地数据库加载可能在后台稍慢；查询在单线程执行，不阻塞主线程。Activity 销毁时清除输入框、忽略异步旧结果。
- 数据库不是号码归属地“实时权威”，新号段可能未收录，某些号段运营商因携号转网变化不准确。没有数据时返回未知，不猜城市，也不根据 SIM / VPN 国家猜省份。

## 回归与真机验收

1. 权限未授权时基础信息可见；详细卡槽明确提示需要用户单独授权，无崩溃。
2. 用户拒绝 `READ_PHONE_STATE` 仍能执行前七位号段的离线查询。
3. 中国双卡/eSIM 设备按 Android API 当前可见 subscription 显示；vivo 分身不等于新的 SIM 卡。
4. 输入 `1380013` 一类七位手机号段时数据库能查到省市，后四位不被请求；超出 7 位无法输入。
5. 号码段不合法、新段数据库缺项时提示失败，不要猜省市。
6. 切换 VPN/模拟位置后，SIM 发卡国家与号段省市仍按 SIM/号段来源展示，不显示 VPN 位置伪装为 SIM 归属地。
7. 正常模拟、停止模拟、VPN 同步和锁定、时区跟随、微信自动诊断总日志行为不受本功能影响。
8. 检查产物中实际已含本地号段数据，并在 vivo 手机上断网试查成功；只有构建成功不能代替运行验证。
