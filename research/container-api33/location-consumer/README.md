# 独立的自有 Android 定位消费者

仅供云端研发，手机用户不需要安装。此 APK 与研究宿主分别构建，不依赖天外天、BlackBox、反射或自定义加载接口；普通 Activity 通过 `getSystemService(LOCATION_SERVICE)` 获取框架 `LocationManager`。

界面提供开始、刷新、停止、取消，展示 GPS／NETWORK 的缓存、单次回调和持续批量回调。坐标仅从 Android API 返回值读取；APK 不包含预期目标坐标，启动 Intent 只有关联本轮的随机 nonce。测试控制器在宿主设置合成目标，并操作真实 Guest 界面。

状态在同一主循环合并后原子写入本应用私有的`files/location-status.json`，同时显示在界面。控制器只读取这个自有测试应用的报告，核对nonce、递增序号和真实单调时钟，避免动态界面读取耗时使单次样本过期；报告及原六类样本仍须在30秒内，没有延长时效或改写定位时间。文件不接收目标坐标，也不读取第三方应用或账号数据。

这个消费者是本项目自编测试应用。它验证真实 Guest 进程的调用链，不能代表第三方 SDK、微信、抖音或海外业务功能。Android 运行时权限申请流程也没有在本轮覆盖。消费者不在宿主普通准入清单内；其导入和定位开启仅在云端 Android 测试代码内，完成后关闭定位并停止该 Guest。
